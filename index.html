이 저장소는

개인 프로젝트를 모아두는 저장소입니다. 지금은 악보 위에 계이름을 자동으로 써주는 파이썬 스크립트가 들어있습니다.

악보 계이름 자동 삽입 스크립트

PDF/JPG/PNG 악보를 입력받아 음표 머리를 검출하고, 오선 위치와 음자리표, 조표를 이용해 실제 음이름을 계산한 뒤 각 음표 위에 고정도 계이름 (도레미파솔라시, 항상 C=도)을 써넣습니다. 마디별 코드 추정 기능도 포함되어 있습니다. 

python scripts/name_on_notes_pitch.py input.pdf -o output.pdf --flats 4
